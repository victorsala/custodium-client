Dónde está

En github.com/victorsala/custodium-client. Contiene el cliente completo, que es lo que corre en tu navegador (el cifrado, las pantallas, el abridor sin conexión), y también el programa del servidor, con su configuración, el esquema de la base de datos y las pruebas automáticas. Sin frameworks y sin compilación: lo que lees es lo que se ejecuta.

Cómo comprobar lo que sirve esta web

Al pie de la página de entrada aparece la versión desplegada; también está en custodium.space/VERSION. Es el identificador de un commit del repositorio.

Con estos comandos descargas cada fichero tal como lo recibe tu navegador y lo comparas con el publicado en ese commit:

git clone https://github.com/victorsala/custodium-client && cd custodium-client
git checkout $(curl -s https://custodium.space/VERSION)
for f in index.html app.js routes.js crypto.js words.js templates.js abrir.html abrir.js aqui.html aqui.js abrir-offline.html fflate.js style.css; do
  diff <(curl -sL "https://custodium.space/$f") "public/$f" && echo "OK $f"
done

Si algún fichero difiere, el comando lo muestra. Cualquiera puede hacerlo, en cualquier momento, sin pedirnos permiso.

Lo que no se puede comprobar desde fuera

Que el servidor ejecute exactamente el programa publicado. Ningún servicio remoto puede demostrarlo. Por eso el diseño no exige confiar en él: todo lo sensible se cifra en el navegador, con código que sí puedes verificar, antes de enviarse. El programa del servidor publicado muestra lo que hace y, sobre todo, lo que no puede hacer: solo maneja datos cifrados, pruebas de acceso con sal y fechas de aviso y entrega.

Sin scripts de terceros

La página no carga código de otros dominios: ni analítica, ni fuentes externas, ni etiquetas de publicidad. Una política de seguridad de contenido lo impide aunque alguien lo intentara. Los cuatro componentes ajenos (dos fuentes tipográficas, una biblioteca para crear archivos zip y la lista de palabras de las frases) están en THIRD_PARTY.md con su licencia.

Licencia

El código es visible y auditable: cualquiera puede leerlo, descargarlo y ejecutarlo en local para verificar el servicio, y usar el abridor incluido en su copia para abrir su propio plan. No es software libre: no permite redistribuirlo, modificarlo ni montar un servicio con él. El texto completo está en LICENSE.
